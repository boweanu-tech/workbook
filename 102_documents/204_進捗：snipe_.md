# 概要
- １ファイル＝１「つ」(考えない)
- 「すぐ欲しいけどlessonの整備が間に合わない問題」をとりあえずストック
- 構造化はしない
- 順次lessonに移行→削除
- 網羅性・・・テーマ列挙で「全部の問題を生成できる」ようにする。
- １ファイルに時間制限は特に無し。
- １ファイルのページ数は自由。
- テーマを各ページ右上に明示する。
	- \MajorQuestion{}の引数にタイトルを入れる。
- 解答は「最後にまとめて」出力する。ページ数は問わず解説は原則なし(生徒に調べさせたいから)。
- ファイル名の通し番号は重複だけはないように。
	- snipe_01.tex(水量と一次関数)
	- snipe_02.tex(一次関数の決定　連立するタイプ)
	- snipe_03.tex(グラフの読み取り)
		- 問題の並び順はカオスでOKです。
		- フォルダはしっかり分類する
