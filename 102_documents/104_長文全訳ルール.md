# 【長文全訳】TeX生成ルールまとめ

最終更新: 2026-09-14

## 目的

画像の英語長文を、次の2ファイルとして出力する。

- `sent.tex`
- `word.tex`

ローカル作業では、指定された入力フォルダーに対応する出力フォルダーへ、この2ファイルを配置する。

## ローカル作業時の入出力

入力画像は、次のルート以下にある。

```text
002_english/translate/input/
```

ユーザーは、その都度 `input/` 以下の相対フォルダーパスを指定する。

例:

```text
heartening/Lesson06
```

この場合、対象画像は次のフォルダー内にある画像すべてとする。

```text
002_english/translate/input/heartening/Lesson06/
```

出力先は、`output/` 以下に入力と同じ相対フォルダーパスを使う。

```text
002_english/translate/output/heartening/Lesson06/
├── sent.tex
└── word.tex
```

画像が複数ある場合も、画像ごとにファイルを分けない。画像を読む順に結合し、指定フォルダー全体で1組の `sent.tex` と `word.tex` を作る。

`word.tex` の単語は、画像の枚数にかかわらず全体から重要な20語に絞る。本文から適切な語を20語抽出できない場合は、従来どおり空の `\AddRow{}{}` を加えて合計20行にする。

## ファイル名・タイトル

タイトルには、ユーザーが指定した `input/` 以下の相対フォルダーパスを使う。パス中の `/` を半角スペースに置き換えた文字列をタイトルとする。画像ファイル名や画像枚数はタイトルに使用しない。

例:

```text
指定フォルダーパス: heartening/Lesson06
```

なら、タイトルは次のようにする。

```text
heartening Lesson06
```

このタイトルを次の2か所に入れる。

`sent.tex`

```latex
\Title{heartening Lesson06}
```

`word.tex`

```latex
\WTReset{日本語}{英語}{heartening Lesson06}
```

指定時に相対フォルダーパスの末尾へ `/` が付いていても、その末尾の `/` はタイトルへ含めない。

ただし、TeXでコンパイルできない特殊文字がフォルダー名に含まれる場合は、見た目の意味を保ったままエスケープする。

特に注意する文字:

```text
_  %  &  #  $  {  }  ^  ~  \
```

例:

```text
course/out_-3
```

の場合、TeX上では必要に応じて次のようにする。

```latex
\Title{course out\_-3}
\WTReset{日本語}{英語}{course out\_-3}
```

## sent.tex の形式

基本形:

```latex
\documentclass[b5j,fleqn]{jarticle}
\usepackage{zennyakuUniv}
\begin{document}
\body{
\Title{タイトル}
\para

\sent{英文}
{日本語訳}
}
\end{document}
```

### 会話文

話者がある会話文では、原則として `\sentP` を使う。

```latex
\sentP{Kate}{How did your team find new members?}{ケイト}{あなたたちのチームはどのようにして新しいメンバーを見つけたのですか？}
```

形式:

```latex
\sentP{英語話者}{英文}{日本語話者}{日本語訳}
```

### 地の文・記事文

通常の長文・記事・説明文では `\sent` を使う。

```latex
\sent{Music is part of our daily lives.}
{音楽は私たちの日常生活の一部です。}
```

### 段落

段落の切れ目では `\para` を入れる。

`\para` は段落どうしの仕切りなので、最後の `\sent` または `\sentP` の後には入れない。

見出しも必要なら `\sent` として入れてよい。

```latex
\sent{The Story of Sadako}
{禎子の物語}
```

### 固定する命令

次の命令はそのまま出力する。

```latex
\documentclass[b5j,fleqn]{jarticle}
\usepackage{memorize}
\begin{document}
\HideLeftTest
\leftSize{45}
\WTReset{日本語}{英語}{タイトル}
\PrintWordTest
\end{document}
```

変更してよいのは次だけ。

- `\WTReset` の第3引数
- `\AddRow{}{} `の各引数

### AddRow

`\AddRow` は最大20個。

単語が20個未満の場合は、空行を追加して合計20行にする。

```latex
\AddRow{}{}
```

書式:

```latex
\AddRow{日本語訳}{英単語}
```

例:

```latex
\AddRow{好む}{like}
\AddRow{訪れる}{visit}
\AddRow{記憶}{memory}
```

## 単語抽出ルール

本文から重要語を抽出する。

優先する語:

- New Words欄に出ている語
- 本文理解に重要な動詞・名詞・形容詞
- 中高生が覚える価値のある語
- 本文特有の語
- 入試長文では抽象語・論理語・設問に関わりやすい語

避ける語:

- 簡単すぎる機能語
- 固有名詞だけの語
- 本文理解にあまり影響しない語
- 熟語として覚えるべきでない細切れ語

本文上重要なら熟語も入れてよい。

```latex
\AddRow{参加する}{take part in}
\AddRow{〜ではなく}{as opposed to}
\AddRow{的外れで}{off the mark}
```

## 翻訳ルール

日本語として自然で、授業で使いやすい全訳にする。

ただし、英文構造を追いやすいように、必要以上に意訳しすぎない。

原則として英文1文ごとに `\sent` または `\sentP` で分ける。

長すぎる英文でも、基本は1英文につき1訳文。

話者名は日本語にして入れる。

例:

```text
Kate → ケイト
Hana → ハナ
Mr. Oka → 丘先生
```

固有名詞は自然なカタカナ表記にする。

例:

```text
Nikola Tesla → ニコラ・テスラ
Bruno Mars → ブルーノ・マーズ
The Beatles → ビートルズ
```

作品名・曲名は、英語名をそのまま残してよい。

```latex
\sent{We'll play "Count on Me."}
{「Count on Me」を演奏します。}
```

## 画像の扱い

ローカル作業では、ユーザーが指定した `input/` 以下の相対フォルダー内にある画像をすべて対象にする。複数画像の本文は読む順に結合し、1つの長文として扱う。

ユーザーが範囲を指定した場合は、その範囲だけを対象にする。

例:

- 「左側のメール本文だけでOK」→ 左ページのメール本文のみ
- 「左側お願いします」→ 左ページ本文のみ
- 「左右の文章ふたつとも」→ 左右両方の本文
- 「2ページに分かれているので1つに合わせて」→ 1つの `sent.tex` と1つの `word.tex` にまとめる
- 「本文だけでOK」→ 設問・注・New Words欄は原則として除外する

画像の端で英文が途中までしか見えていない場合は、見えている範囲で作る。

返答時には必要に応じて次のように伝える。

```text
文末が画像外で切れているため、見えている範囲で作成しました。
```

## TeXコンパイル上の注意

本文中の次の文字は必要に応じてエスケープする。

```text
%  _  &  #  $  {  }  ^  ~  \
```

特に `%` はコメント扱いになるので必ず注意する。

```latex
74\%
```

顔文字はTeXで壊れやすい。

例:

```text
^_^
^_^;
:)
```

必要に応じて、TeXで通る形にする。

例:

```latex
\textasciicircum{}\_\textasciicircum{}
```

または、スタイルファイル側で安全に処理できる形式がある場合はそれに従う。

## 出力方法

作成するファイル:

```text
sent.tex
word.tex
```

ローカル作業では、ユーザーが指定した入力相対フォルダーと同じ相対フォルダーを `output/` 以下に作り、その中へ2ファイルを直接配置する。

例:

```text
入力指定: heartening/Lesson06

入力画像:
002_english/translate/input/heartening/Lesson06/p80.jpg
002_english/translate/input/heartening/Lesson06/p81.jpg

出力:
002_english/translate/output/heartening/Lesson06/sent.tex
002_english/translate/output/heartening/Lesson06/word.tex
```

チャットに画像が直接添付され、ローカル出力先がない場合に限り、2ファイルをzipにまとめる。

```text
tex_files.zip
```

返答では短い説明とリンクを返す。

例:

```text
こちらです。

[texファイル一式をダウンロード](sandbox:/mnt/data/.../tex_files.zip)
```

## 重要修正履歴

### word.tex の package

誤り:

```latex
\usepackage{WordTest}
```

正しい形式:

```latex
\usepackage{memorize}
```

### word.tex の命令

次を必ず入れる。

```latex
\HideLeftTest
\leftSize{45}
\PrintWordTest
```

### AddRow

誤り:

```latex
\addLH{日本語}{英語}
```

正しい形式:

```latex
\AddRow{日本語}{英語}
```

### タイトル

指定された `input/` 以下の相対フォルダーパスが `heartening/Lesson06` の場合、正しい形式は次。

```latex
\Title{heartening Lesson06}
\WTReset{日本語}{英語}{heartening Lesson06}
```

ただし、TeX特殊文字がある場合はコンパイル可能な形にする。
