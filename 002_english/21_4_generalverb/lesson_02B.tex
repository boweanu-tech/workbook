\LessonPageBreak

\TypeQuestion{日本語に合うように、（　）内では適切な語を丸で囲み、空欄には選択肢から適切な語を入れなさい。また、完成した正しい英文を書きなさい。}{generalverb_negative_fill_choice}
\EngWriteQuestion{私は野球をしません。\par\EngSentence{I \EngChoice{do / am} not play baseball.}}{}
\EngWriteQuestion{私たちはこの本を読みません。\par\EngSentence{We \EngChoice{don't / aren't} read this book.}}{}
\EngWriteQuestion{私は犬が好きではありません。\par\EngSentence{I \EngChoice{do / don't} like dogs.}}{}
\EngWriteQuestion{あなたは忙しくありません。\par\EngSentence{You \EngChoice{are / do} not busy.}}{}
\EngWriteQuestion{彼らは生徒ではありません。\par\EngSentence{They \EngBlank[18mm] students.}\par\EngChoice{aren't / don't / not}}{}
\EngWriteQuestion{私たちはこの部屋を使いません。\par\EngSentence{We \EngBlank[18mm] use this room.}\par\EngChoice{don't / aren't / not}}{}

\LessonPageBreak

\TypeQuestion{英文の右の指示に従って、文を書き換えなさい。}{generalverb_negative_transform}
\EngWriteQuestion{\EngSentence{I do not use this computer.}\quad〔短縮形を使って〕}{}
\EngWriteQuestion{\EngSentence{They don't like cats.}\quad〔短縮形を使わずに〕}{}
\EngWriteQuestion{\EngSentence{I like dogs.}\quad〔否定文に〕}{}
\EngWriteQuestion{\EngSentence{We don't use this room.}\quad〔肯定文に〕}{}
\EngWriteQuestion{\EngSentence{I am busy.}\quad〔否定文に〕}{}

\LessonPageBreak

\TypeQuestion{日本語に合うように、〔　〕内のすべての語句を並べ替えて、正しい英文を作りなさい。}{generalverb_negative_reorder}
\EngWriteQuestion{私はテニスをしません。\par\EngReorder{tennis / do not / i / play}}{}
\EngWriteQuestion{私たちは放課後に英語を勉強しません。\par\EngReorder{after school / don't / English / we / study}}{}
\EngWriteQuestion{私は忙しくありません。\par\EngReorder{busy / not / am / i}}{}
\EngWriteQuestion{彼らは生徒ではありません。\par\EngReorder{students / not / are / they}}{}
\EngWriteQuestion{あなたはこの部屋を使いません。\par\EngReorder{this room / use / don't / you}}{}
\EngWriteQuestion{私たちは友達ではありません。\par\EngReorder{friends / aren't / we}}{}
