\TypeQuestion{異なるものを一列に並べる方法は何通りあるか。}{linear_permutations}
\QQRow{異なる7冊の本を本棚に一列に並べる。}{}{6人が一列に並んで写真を撮る。}{}
\QQRow{8枚の異なるカードから5枚を選んで一列に並べる。}{}{9人の選手から金・銀・銅メダルを受け取る3人を順位をつけて選ぶ。}{}
\QQRow{7人から会長、副会長、書記を1人ずつ選ぶ。ただし、1人が2つ以上の役職を兼ねることはできない。}{}{異なる10冊の本から4冊を選び、左から順に並べる。}{}

\TypeQuestion{指定された数字を使って、条件を満たす整数を作る方法は何通りあるか。同じ数字は繰り返し使わないものとする。}{numbers_without_repetition}

\QQRow{数字 $0,1,2,3,4,5,6,7$ から5個を使って作る5桁の奇数。}{}{数字 $0,1,2,3,4,5,6,7,8$ から4個を使って作る4桁の5の倍数。}{}
\QQRow{数字 $0,1,2,3,4,5,6$ から4個を使って作る4桁の偶数。}{}{数字 $0,1,2,3,4,5,6,7$ から5個を使って作る、42000より大きい5桁の整数。}{}

\QQRow{男子4人、女子4人が一列に並ぶ。男女が交互に並ぶ方法。}{}{7人が一列に並ぶ。$\mathrm{A}$ が $\mathrm{B}$ より左に並ぶ方法。}{}

\TypeQuestion{特定のものが隣り合う並べ方を求めなさい。}{adjacent_permutations}
\QQRow{7人が一列に並ぶとき、$\mathrm{A}$ と $\mathrm{B}$ が隣り合う方法。}{}{8冊の異なる本を一列に並べるとき、指定された3冊が続けて並ぶ方法。}{}
\QQRow{男子4人、女子3人が一列に並ぶとき、女子3人が続けて並ぶ方法。}{}{国語の本3冊、数学の本2冊、英語の本2冊を一列に並べるとき、同じ教科の本がそれぞれまとまって並ぶ方法。ただし、7冊はすべて異なる。}{}
\QQ{8人が一列に並ぶとき、$\mathrm{A}$ と $\mathrm{B}$ が隣り合い、さらに $\mathrm{C}$ と $\mathrm{D}$ も隣り合う方法は何通りあるか。}{}

\TypeQuestion{特定のものが隣り合わない並べ方を求めなさい。}{nonadjacent_permutations}
\QQRow{7人が一列に並ぶとき、$\mathrm{A}$ と $\mathrm{B}$ が隣り合わない方法。}{}{8冊の異なる本を一列に並べるとき、指定された2冊の間にちょうど1冊の本が入る方法。}{}
\QQRow{男子4人、女子4人が一列に並ぶとき、両端がともに男子となる方法。}{}{8人が一列に並ぶとき、$\mathrm{A}$ と $\mathrm{B}$ の間にちょうど2人が並ぶ方法。}{}
\QQ{6人が一列に並ぶとき、$\mathrm{A}$ と $\mathrm{B}$ が隣り合わず、$\mathrm{C}$ と $\mathrm{D}$ も隣り合わない方法は何通りあるか。}{}

\TypeQuestion{順序や位置に複数の条件がある並べ方を求めなさい。}{permutation_constraints}
\QQ{男子4人、女子4人が一列に並ぶ。女子が左端と右端の少なくとも一方に並ぶ方法は何通りあるか。}{}
\QQ{異なる7冊の本を一列に並べる。指定された本 $\mathrm{A}$ が本 $\mathrm{B}$ より左にあり、2冊が隣り合わない並べ方は何通りあるか。}{}
\QQ{8人が一列に並ぶ。$\mathrm{A}$ は $\mathrm{B}$ より左、$\mathrm{C}$ は $\mathrm{D}$ より左に並ぶ方法は何通りあるか。}{}
\QQ{6人が横一列の6席に座る。$\mathrm{A}$ と $\mathrm{B}$ は隣り合い、$\mathrm{C}$ は端の席に座らない座り方は何通りあるか。}{}
