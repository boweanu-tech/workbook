\MajorQuestionLesson{円順列・じゅず順列}
\SetRowSpace{4mm}

\TypeQuestion{異なるものを円形に並べる方法は何通りあるか。回転して一致する並べ方は同じものとする。}{basic_circular_permutations}
\QQRow{異なる6人が円形のテーブルに座る。}{}{異なる8個の飾りを円形の台に並べる。}{}
\QQRow{7人が輪になって手をつなぐ。}{}{異なる9枚のカードを円周上に等間隔で並べる。}{}
\QQ{先生1人と生徒7人が円形のテーブルに座る。先生の位置を固定して考えるとき、生徒の座り方は何通りあるか。}{}

\TypeQuestion{特定のものの位置に条件がある円順列を求めなさい。}{circular_position_constraints}
\QQRow{異なる7人が円形のテーブルに座る。$\mathrm{A}$ と $\mathrm{B}$ が隣り合う座り方。}{}{異なる8人が円形のテーブルに座る。$\mathrm{A}$ と $\mathrm{B}$ が向かい合う座り方。}{}
\QQRow{異なる7人が円形のテーブルに座る。$\mathrm{A}$ と $\mathrm{B}$ が隣り合わない座り方。}{}{異なる9人が円形のテーブルに座る。$\mathrm{A}$ の両隣に $\mathrm{B}$ と $\mathrm{C}$ が座る方法。}{}
\QQ{異なる8人が円形のテーブルに座る。$\mathrm{A}$ と $\mathrm{B}$ が隣り合い、$\mathrm{C}$ と $\mathrm{D}$ も隣り合う座り方は何通りあるか。}{}
\QQ{異なる10人が円形のテーブルに座る。$\mathrm{A}$ と $\mathrm{B}$ の間に、円周に沿った一方の側でちょうど2人が座る方法は何通りあるか。}{}

\TypeQuestion{男子と女子を円形に並べる方法を求めなさい。}{alternating_circular_permutations}
\QQRow{男子4人、女子4人が円形のテーブルに男女交互に座る。}{}{男子5人、女子5人が輪になって男女交互に並ぶ。}{}
\QQ{4組の夫婦が円形のテーブルに座る。男女が交互に座る方法は何通りあるか。}{}
\QQ{4組の夫婦が円形のテーブルに座る。それぞれの夫婦が隣り合う座り方は何通りあるか。}{}
\QQ{男子5人、女子4人が円形のテーブルに座る。女子どうしが隣り合わない座り方は何通りあるか。}{}

\TypeQuestion{異なる玉をひもで輪につなぎ、首飾りを作る方法は何通りあるか。回転または裏返して一致するものは同じ首飾りとする。}{basic_necklace_permutations}
\QQRow{異なる6個の玉で首飾りを作る。}{}{異なる8個の玉で首飾りを作る。}{}
\QQRow{異なる7個の玉で首飾りを作り、指定された2個の玉を隣り合わせる。}{}{異なる9個の玉で首飾りを作り、指定された2個の玉が隣り合わないようにする。}{}
\QQ{異なる8個の玉で首飾りを作る。指定された3個の玉が続けて並ぶものは何通りあるか。}{}

\TypeQuestion{円順列またはじゅず順列として、次の場合の数を求めなさい。}{circular_or_necklace}
\QQ{異なる7種類の料理を回転する円形トレーに並べる。トレーを回転して一致する並べ方は同じとし、トレーを裏返すことはできない。並べ方は何通りあるか。}{}
\QQ{異なる8個の鍵を1本の開閉できる輪に通す。輪を回転したり裏返したりして一致する通し方は同じとする。通し方は何通りあるか。}{}
\QQ{円形の花壇の周囲に、異なる6種類の立札を立てる。北側の位置が決められているため、回転させて一致する配置も異なるものとして数える。配置は何通りあるか。}{}
\QQ{異なる7個の飾りを輪につないでブレスレットを作る。ただし、表裏があり、裏返して一致するものは異なるものとする。作り方は何通りあるか。}{}

\TypeQuestion{条件を満たす円形または首飾りの並べ方を求めなさい。}{advanced_circular_necklace}
\QQ{異なる8人が円形のテーブルに座る。$\mathrm{A},\mathrm{B},\mathrm{C}$ の3人のうち、どの2人も隣り合わない座り方は何通りあるか。}{}
\QQ{5組の夫婦が円形のテーブルに座る。それぞれの夫婦が向かい合う座り方は何通りあるか。}{}
\QQ{異なる8個の玉で首飾りを作る。指定された2個の玉が向かい合うものは何通りあるか。}{}
\QQ{異なる9個の玉で首飾りを作る。指定された2個の玉の間に、一方の側でちょうど2個の玉が入るものは何通りあるか。}{}
